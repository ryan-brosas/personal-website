04 / Radius + elevation

Flat first. Raised only when needed.

Geometry signals purpose. Editorial blocks stay square, controls soften slightly, panels stop at 8px, and pills are reserved for short statuses.

0px / editorial

Evidence plate

Large statements, dark heroes, and color fields.

4px / control

Button or input

Compact, functional, and never bubbly.

8px / panel

Workbench module

The maximum radius for ordinary surfaces.

999px / status only

Verified

Never use pill geometry for every control.

Default / structural rule

Calm and flat.

Use a 1px rule for most separation. Whitespace does more work than shadow.

Raised / temporary layer

One soft shadow.

Reserve elevation for sticky navigation, menus, overlays, and transient feedback.

Anti-pattern: no glow, no layered glass cards, and no shadow under the production logo.
