05 / Agent system map

Inspect the whole workflow.

This sequence is a decision component, not a progress meter. Keep all five steps and use a concrete operating question for each one.

  1. 01

    Context

    What must the system know before work begins?

  2. 02

    Work

    What action actually changes the operating state?

  3. 03

    Checks

    How do we know the output is safe to use?

  4. 04

    Handoffs

    What context must survive between people and tools?

  5. 05

    Recovery

    Who owns the failure path when automation stops?

Recovery records the failure context, then improves the next Context.
