title: Hallucination
description: Hallucination is when a model states a false fact as if it were true.
pillar: agent-reliability
---

It does not know it is wrong. The text can look clean and sound sure.

This happens because the model guesses the next word. It does not look up facts unless you give it a way to. Confident tone is not the same as truth.

Cut hallucination by giving the model sources and asking it to cite them. When a fact matters, check it yourself. Never trust a clean sentence by itself.
