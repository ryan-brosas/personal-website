title: Context windows
description: A context window is how much text a model can look at in one turn.
pillar: context-knowledge-systems
---

It has a fixed size. When the text gets too long, the oldest parts fall out of view.

A bigger window lets the model use more notes at once. But more text is not always better. The model can lose track of key facts in the middle of a long pile.

Pick what goes in the window on purpose. Keep the useful facts near the top. Drop what no longer matters. A full window is not the same as a useful one.
