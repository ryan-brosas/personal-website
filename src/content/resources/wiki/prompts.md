title: Prompts
description: A prompt is the instruction you give the model.
pillar: context-knowledge-systems
---

It sets the job, the shape of the answer, and the rules the model should follow.

Small changes in a prompt can change the result a lot. A clear prompt names the task and the output you want. A vague prompt leaves the model to guess.

Keep prompts short and test them. When a prompt grows long, split it into parts. A prompt that works once may not work on a new task. Save the ones that work and note why.
