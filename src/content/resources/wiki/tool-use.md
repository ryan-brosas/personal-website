description: Tool use means an agent can call other programs to help it work.

It can search the web, run code, look up a fact, or send a message.

Each tool has a fixed job and fixed inputs. The agent picks the right tool and gives it the right values. The tool returns a result the agent can read.

Tools make agents more useful and more safe. The agent does not have to guess. It can check facts instead of making them up. Give tools a clear shape so the agent uses them well.
