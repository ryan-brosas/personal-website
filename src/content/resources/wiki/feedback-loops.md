title: Feedback loops
description: A feedback loop is when the result of one run changes how the next run works.
pillar: ai-workflow-systems
---

Good feedback makes the system better over time. Bad feedback makes it worse.

A good loop collects real outcomes, learns from them, and updates the rules. A bad loop only hears what it wants and grows more sure of the wrong thing.

Make the feedback easy to see. Track what changed and why. A loop you cannot watch is a loop you cannot fix.
