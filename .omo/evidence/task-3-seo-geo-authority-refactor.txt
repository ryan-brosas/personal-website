## Key design decision
Vite sets NODE_ENV=production internally before evaluating astro.config.mjs during
ANY astro build invocation (including test-invoked builds via spawnSync). Therefore
NODE_ENV is not a reliable discriminator for "real production build" vs "test build".
Guard fires only when SITE_ORIGIN is explicitly set to the placeholder value — this
catches the operator mistake of copying the placeholder into CI/CD env vars, while
allowing absent SITE_ORIGIN (normal dev/test state) to fall back silently.
