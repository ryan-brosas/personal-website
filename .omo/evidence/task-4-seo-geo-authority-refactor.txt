WHY A STOPGAP (conflict found during analysis)
----------------------------------------------
The registry's manifest helpers are intentionally AHEAD of the current build:
- expectedBuildManifest() returns string[] (NOT the object the task brief described)
  and INCLUDES "/case-studies/" (reserved hub, gate "case-studies-hub", not built
  until T14). discoverableRoutes() also includes it (locked by
  tests/route-registry.test.mjs:163).
- favicon.svg is a public/ static asset copied to dist root — it is NOT a registry
  route and can never come from the registry.
A naive "derive everything from the registry" therefore fails the actual build
(missing-route: /case-studies/, sitemap-missing: .../case-studies/) and cannot
verify favicon without a literal.

TWO SANCTIONED DEVIATIONS from the original "zero literals" wording
------------------------------------------------------------------
(a) favicon.svg — one declared string literal in expectedFileEndpoints (public/
    static asset, not a registry route). Documented with an inline comment.
(b) gate === "always" heuristic — layered in the verifier/test derivation (NOT in
    the registry) to exclude the reserved case-studies hub. The code-owned noindex
    root (visibility "noindex") is kept via an OR clause. This encodes gate-open
    policy the registry does not yet evaluate; it converges cleanly at T14.

DERIVATION (identical in verify-build.mjs CLI entry and shell.test.mjs)
----------------------------------------------------------------------
  const defs = ROUTE_REGISTRY.all();
  expectedHtmlRoutes = defs.filter(d =>
      d.isDynamic !== true && isHtmlRoute(d.path) &&
      (d.gate === "always" || d.visibility === "noindex")).map(d => d.path);
      -> ["/", "/services/", "/about/", "/contact/"]      (drops /case-studies/)
  expectedDiscoverableRoutes = ROUTE_REGISTRY.discoverableRoutes()
      .filter(r => r.gate === "always").map(r => r.path);
      -> ["/services/", "/about/", "/contact/"]           (drops /case-studies/, home)
  expectedFileEndpoints = defs.filter(d =>
      d.isDynamic !== true && !isHtmlRoute(d.path)).map(d => d.path.replace(/^\/+/, ""))
      .concat("favicon.svg");
      -> ["sitemap.xml", "robots.txt", "404.html", "favicon.svg"]
  site = process.env.SITE_ORIGIN ?? "https://example.com"   (same pattern as route-registry.ts)
